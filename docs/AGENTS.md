# Documentation instructions

Use the [documentation index](README.md) to locate the guide that owns the topic. Read [knowledge maintenance](knowledge.md) when adding or changing instructions, recording a lesson, or reorganizing the docs.

- Check the owning implementation or recorded decision when documenting a current fact. Mark proposals, design targets, and outstanding decisions explicitly.
- Preserve useful inbound links when moving a section. Update close callers such as the README, contribution prompt and PR template when the owning guide changes.
- Update instructions at the narrowest scope that applies. Use `AGENTS.md` for rules an agent must act on and link to the owning guide for context, examples and rationale.
- Verify changed relative links, anchors, paths, and commands. A documentation-only edit needs evidence appropriate to those changes.
