# Editable characters and production tools

Read the relevant [character source guide](README.md), [character factory notes](Factory.md), or [motion guide](Motion/README.md). Use the [character directory](Directory.md) to locate a resident and the [story directory](../commonstreet/stories/residents/directory.md) to check canon.

- Preserve resident IDs, source receipts and shared rig and package assumptions. Confirm the specific character and affected geometry, appearance, or motion before rebuilding.
- Keep native masters and runtime resources in their expected relative layout. Inspect changes to generated manifests and checksums with the files they describe.
- Prefer the smallest relevant review or regeneration command. Check both source fit and in-game behavior when the change affects both. [Runtime asset instructions](../commonstreet/assets/AGENTS.md)
