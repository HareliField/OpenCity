# Character Build Test

The Commonstreet base character comparison and the six fitted Meshy-based garments from the cloth preview. Import `character.glb` and the six garment GLBs with identity transforms to assemble the outfit. Each GLB contains its own textures.

| File | Model |
| --- | --- |
| [`character.glb`](character.glb) | Optimized character with the body and eyelid shading repaired (3.399 MB, 52,000 triangles) |
| [`character-color-matched.glb`](character-color-matched.glb) | Optimized character with the same repairs and colors matched to the reference (3.394 MB, 52,000 triangles) |
| [`character-original.glb`](character-original.glb) | Original Meshy export, `Meshy_AI_Red_Jacket_Portrait_20261128_texture (1).glb` (83.131 MB, 1,087,922 triangles) |
| `cap.glb` | Cap |
| `coat.glb` | Jacket |
| `jeans.glb` | Jeans |
| `t-shirt.glb` | T-shirt |
| `socks.glb` | Left and right socks |
| `shoes.glb` | Left and right shoes |

[Full-resolution Meshy wardrobe downloads](../../Meshy%20Sources/Character%20Build%20Test%20Originals/README.md)

The three character files are alternatives for comparison. Each was verified as one watertight shell. The fitted garments were tested with `character.glb`. Cloth simulation runs in the separate preview. The jacket sleeve and shoe heel still have visible openings in some views.
