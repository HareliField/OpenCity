# Character Build Test

The eyelid-fixed Commonstreet character and the six fitted Meshy-based garments from the cloth preview. The GLBs contain their textures and share the same scale and origin. Import all seven with identity transforms to assemble the outfit.

| File | Model |
| --- | --- |
| `character.glb` | Eyelid-fixed character |
| `cap.glb` | Cap |
| `coat.glb` | Jacket |
| `jeans.glb` | Jeans |
| `t-shirt.glb` | T-shirt |
| `socks.glb` | Left and right socks |
| `shoes.glb` | Left and right shoes |

The GLBs store the fitted geometry and materials. Cloth simulation runs in the separate preview. The jacket sleeve and shoe heel still have visible openings in some views.
