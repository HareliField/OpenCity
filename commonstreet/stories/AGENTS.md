# Residents and stories

Start with the [resident collection](residents/README.md) and [directory](residents/directory.md). Read the relevant episode and linked people. Use the [city design guide](../../CONTRIBUTING.md#residents-homes-jobs-and-personality) for homes, roles, routines, and histories.

- Keep a resident's name, `AH-R` ID, relationships, commitments, and existing appearances consistent. Preserve department IDs where they apply.
- A written story can establish city canon. Mark any required game behavior that still needs implementation. For a playable story, follow the [adventure brief](../../docs/product.md#adventure-brief).
- If the change affects a compiled persona or runtime casting, locate its pipeline before editing and verify the same person's linked entries. [Character source instructions](../../Character%20Sources/AGENTS.md)
